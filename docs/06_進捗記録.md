# Dungeon Game 進捗記録

## 使い方

ロードマップ(`03_開発ロードマップ`)§7の決まりに従い、フェーズごとの進み具合を記録する。

- 各フェーズが終わったら、「記録」の節に、下の様式で追記する。
- 「現在の状況」の表も、あわせて更新する。
- 「正式採用バージョン」には、Gitのタグ(または、コミットの番号)を書く。
